# Extensions

Browser integration assets for SignalRAG.

- [`signalrag-chromium/`](signalrag-chromium/) is the Manifest V3 extension with
  omnibox search, selected-text search, side panel search, and local API
  options.
- [`signalrag-search-provider/`](signalrag-search-provider/) is the minimal
  search-provider manifest for browser search-engine integration.

These extensions expect a local SignalRAG server, usually
`http://127.0.0.1:8000`.
