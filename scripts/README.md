# Scripts

Top-level helper scripts for the main SignalRAG app and browser integration.

- `generate_extension_icons.py` creates extension icon assets.
- `install_signalrag_chrome.py` helps install or register the Chromium
  extension locally.
- `launch_signalrag_chrome.sh` launches a local Chromium profile for testing the
  SignalRAG extension.

Benchmark and research scripts live with their owning subproject under
`evals/` or `tools/`.
